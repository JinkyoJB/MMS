## 4. Artec 으로 전환 — 지금 상태

`mms/sensor/artec/` 디렉터리가 이미 있고 빌드된 `.pyd` 도 존재.

```
artec_client.py        — Facade (ArtecConfig, ArtecClient)
artec_capturing.py     — ScannerManager / Scanner / FrameProcessor
artec_base.py          — IFrameMesh / IModel / IScan
artec_scanning.py      — ScanSession (preview/record/stop)
artec_algorithm.py     — Serial/Global Registration, Fusion, Texturize
artec_project.py       — .sproj save/load
binding_test.py        — 단위 테스트
```

`MMS(MMSConfig(artec=ArtecConfig(...)))` 로 생성 가능 (system.py 가 이미
artec 분기 가짐). `MMS.capture_frames(n)` 도 Artec 에서 동작 — 단,
**한 번의 capture = IFrameMesh** 단위라 PhoXi 의 organized Range 와는 모양이 다름.

### 4.1 PhoXi vs Artec 데이터 모델 차이

| | PhoXi | Artec |
|---|---|---|
| 한 번의 capture | organized Range (H×W×3) — 픽셀당 (X,Y,Z) | IFrameMesh (vertices + faces) |
| Depth image | (H, W) 직접 사용 | 없음 (mesh 만) |
| 조직화 (organized) | yes | no |
| 내부 SLAM | 없음 (외부 ICP 사용) | 있음 (ScanSession 이 내부 정합) |
| Streaming 단위 | 단발 trigger (~1Hz) | 30+ FPS, 연속 |
| 기본 사용 패턴 | "포즈 잡고 1샷" | "들고 흝기" — 우리는 EE 고정이라 변형 |

### 4.2 영향 받는 컴포넌트 (Artec 으로 갈 때 손볼 부분)

| 컴포넌트 | PhoXi 가정 | Artec 적용 시 |
|---|---|---|
| `PcdAccumulateVolume.integrate_frame` | `sensor._last_organized_pts` (H,W,3) 직접 읽음 | **TODO**: Artec 은 IFrameMesh.vertices() 만 있음. organized 가 아니라 (N,3). |
| `TSDFScanVolume.integrate_frame` | `frame.depth` (H,W) + intrinsic 필요 | **N/A** — Artec 은 depth 가 없으니 이 backend 사용 불가 |
| `InstantMeshingScanVolume` | PhoXi C API 전용 | **N/A** |
| `scan_session._build_current_frame_pcd_C` | `_last_organized_pts` 픽셀 필터링 | **TODO**: `frame.points` 직접 사용 |
| `PhoxiDatasetReplay` | PhoXi-only 포맷 | **새로 작성 필요**: `ArtecDatasetReplay` |
| `phase1_from_dataset.py` | PhoXi replay 사용 | 위 replay 새로 작성 후 평행하게 작성 |

### 4.3 Artec 캘리브레이션

| 항목 | 상태 | 비고 |
|---|---|---|
| Hand-Eye `T_E_C_artec` | ❌ placeholder | `config/calibration/sensor_frames.yaml` 에 identity 기본값. 새로 캘리브 필요. |
| Turntable `T_B_F0` | ✅ 재사용 가능 | 로봇·턴테이블 위치 안 바뀌면 그대로 |
| Artec 시리얼 | `SP.10.36181288` (yaml 주석) | `ArtecConfig(serial_number=...)` 에 넣을 값 |

## 7. 결정 사항 (오늘 메모리에 추가)

  경로는 제거됨. 다시 도입하지 않는다 (필요하면 mesh 후처리에서 별도 단계).
- **Artec 마운트 J7 -45° 가 기본.** `go_home` 의 디폴트가 artec.
